# 欢迎使用 Mango 主题 🥭

这是一个基于 Astro 构建的微信朋友圈风格图片博客主题。

## 特性

- 📱 **响应式设计** - 完美适配各种设备
- 🌙 **暗黑模式** - 保护你的眼睛
- 🎨 **微信朋友圈风格** - 熟悉的交互体验
- ⚡ **极速加载** - Astro 构建的静态站点
- 📝 **Markdown 支持** - 方便的内容管理
- 🖼️ **图片画廊** - 优雅的展示方式

## 快速开始

1. 克隆项目
2. 安装依赖：`npm install`
3. 启动开发服务器：`npm run dev`
4. 访问 `http://localhost:4321`

## 内容管理

本主题集成了 Decap CMS，可以通过 `/admin` 路径访问后台管理界面。

```bash
# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 部署

推荐部署到 Cloudflare Pages：

1. 连接 GitHub 仓库
2. 设置构建命令：`npm run build`
3. 设置输出目录：`dist`

享受你的博客之旅吧！🎉
