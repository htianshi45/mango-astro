Mango 主题一比一复刻：差距清单与改造规格

对比基准：原版演示站 https://mango.huitheme.cn/（不是介绍页 huitheme.com/mango-theme.html） 被评对象：/Users/ming/mango-astro，本地 http://localhost:4321/ 分析日期：2026-11-06 ｜ 版本 v1.0 证据：原版 style.css（31KB，Theme Version 1.6.20241202）、原版首页 HTML（57KB）、两边 1440px 截图

0. 结论先说

这不是「细节没调好」，是骨架级偏差：Qoder 做的是「一个朋友圈风格的通用博客」，而不是 Mango 的复刻。最影响观感的 6 个根因：

  1. 主题色错了：原版整站是蓝色 #4270f5，本地 tailwind.config.mjs 把 mango 定义成红色 #ff5252 → 标签、置顶、序号、hover 全红。
  2. 容器宽度错了：原版 .container{max-width:900px}，本地 max-w-6xl（1152px）→ 所有元素被放大约 28%，窄版双栏的「精致感」消失。
  3. 首屏轮播整个缺失：原版首屏是 2 帧大图 carousel（带「置顶精彩」蓝标、渐变标题、右下指示点），本地直接从文章列表开始。
  4. 导航结构错了：原版是分类菜单（风景/旅拍/科技⌄/主题下载/旅游地图）+ 搜索 + 深色切换，本地是 首页/归档/标签/关于。
  5. 文章卡片内部版式错了：原版正文/图片/标签/数据行从头像右侧缩进 60px，图片区只占内容宽 66%，且按图片数量 2–9 自动布局；本地全部贴左、图片占满宽、等分 grid。
  6. 侧栏组件错配：原版是「热门文章（首条大图）/ 热门标签 / 最近评论」，本地是「最新文章 / 热门文章（红序号）/ 标签云（粉 pill）」。

其余：背景纹理、页脚深色、搜索、灯箱、分页、详情页结构、暗色色板、Bootstrap Icons 图标体系也都未对齐。

2. 首屏结构（P1）

原版首页 DOM 顺序（来自首页 HTML）：

header.sticky-top > .container > .top(.top_l.logo + nav.header-menu + .top_r[搜索/主题])
main .container > .row
  ├─ .col-lg-8
  │    ├─ .index_banner > #banner.carousel.slide > .carousel-inner > .banlist ×2
  │    │     └─ 左上蓝标「置顶精彩」/ 底部白字标题 / 右下 10px 圆点 / hover 左右 40px 圆按钮
  │    └─ .post_loop ×8（每页 8 条）
  └─ .col-lg-4
       └─ .widget ×3：热门文章 / 热门标签 / 最近评论
footer.footbox（深色）

本地：header → grid(文章列表 / 3 个 widget) → footer，没有 .index_banner、没有搜索、没有分页。

轮播关键数值（原版 CSS 原文）：

  • .index_banner{margin-bottom:25px}
  • .banlist:before{background:linear-gradient(to top,black,#ffffff00);opacity:.6}
  • .banlist h2{position:absolute;bottom:0;color:#fff;font-size:16px;padding:20px 25px}
  • .banlist i{background:#4270f5;font-size:12px;padding:3px 7px}（左上角标签）
  • #banner .carousel-indicators{right:20px;bottom:14px;justify-content:flex-end}；button{width:10px;height:10px;border-radius:50%}
  • #banner:hover .banlist img{transform:scale(1.1)}；左右控制 i 40×40 圆形 #242424，hover #4270f6

轮播数据可放 src/config/banner.ts，2–3 帧；用 Bootstrap Carousel（MIT）或原生 JS 都行，静态站完全可实现。

7. 验收清单（改完逐项打勾）

  • ☐ 1440px 截图：内容区总宽约 900px 且居中，左栏 600 / 右栏 300

  • ☐ 侧栏顺序与样式：热门文章（大图）→ 热门标签 → 最近评论
  • ☐ 页脚深色 #1f2327，含备案/版权/友链

附：合规提示

Mango 是绘主题发布的免费 WordPress 主题，介绍页明确写着「免费主题请保留底部版权信息」。本次分析只读取了公开演示页的 HTML/CSS 用于视觉比对。若要公开发布复刻版：

  • 不要直接拷贝原主题的 CSS、图片、字体、JS 文件；按数值重写等价实现（本规格已给出全部关键数值）。
  • 保留或替换成你自己的版权信息，遵守原主题授权条款。
  • Bootstrap / Bootstrap Icons / Pagefind / GLightbox / PhotoSwipe 均为 MIT，可自由使用；Fancybox 有单独许可，建议替换。
