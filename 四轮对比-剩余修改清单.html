3. 🐛 两个本轮新引入的 bug（优先修）

3.1 桌面端多出一个汉堡菜单按钮

现象：对照图下半部分顶栏右侧有 3 个圆形按钮（放大镜 / 灯泡 / 列表），原版只有 2 个。1440px 视口下移动端菜单按钮本该隐藏。

根因（CSS 特异性）：Header.astro 给按钮同时写了 class="lg:hidden header-icon-btn"，而组件 <style> 里：

.header-icon-btn { display: flex; ... }

构建后变成 .header-icon-btn[data-astro-cid-3ef6ksr2]{display:flex}，特异性 (0,2,0)；Tailwind 的 @media(min-width:1024px){.lg\:hidden{display:none}} 只有 (0,1,0)。media query 不提升特异性 → display:flex 胜出，按钮在桌面端依然显示。

修复（任选其一，推荐 A）：

/* A：在 Header.astro 的 <style> 里加，ID 特异性稳赢 */
@media (min-width: 1024px) {
  #mobile-menu-toggle { display: none; }
}

<!-- B：把 display 交给 Tailwind，从 scoped CSS 里删掉 display:flex -->
<button id="mobile-menu-toggle" class="header-icon-btn flex lg:hidden" ...>

3.2 暗色模式用 filter: brightness(0.85) 整体降亮度

global.css:10-12 现在是：

.dark {
  --ds_background: url("/images/bg-wave.svg");
  filter: brightness(0.85);   /* ⚠️ 删掉 */
}

两个副作用：

  1. 破坏原版暗色配色：原版是逐项精确设色（.dark .post_loop/.widget/#212121、.dark .header/.footbox/#151516、.dark .links/#1d1d1d、.dark .widget-title:after/#191919、.dark .posts-nav .page-numbers/#2a2a2b、.dark .post_loop_tag em/#343435、.dark .widget_comment_ul li/#252525），整体降亮度会把白卡变灰、图片变暗，色值全对不上；
  2. filter 会创建新的包含块，使 position:fixed 的 BackToTop / 搜索遮罩不再相对视口定位，滚动时可能跟着内容跑。

修复：删掉 filter，按原版色值补一份集中的 .dark 规则表，并覆盖 Banner / Footer / 背景纹理：

.dark body { background-color:#191919; color:#c9c9c9; background-blend-mode:overlay; }
.dark .post-loop, .dark .widget, .dark .post_container_title,
.dark .post_container, .dark .post_author, .dark .post_related { background:#212121; }
.dark .site-header, .dark .site-footer { background:#151516; }
.dark .widget-title::after { background:#191919; }
.dark .post-tag { background:#343435; }
.dark .comment-item { border-bottom-color:#252525; }
.dark .banlist-overlay { /* 轮播遮罩按原版保持即可 */ }
.dark .site-footer .links a { color:#999; }

建议顺手做一次暗色实测截图（当前四轮对照只做了浅色），确认无漏改、无整体发灰。
