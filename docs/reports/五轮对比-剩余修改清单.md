## 3. 🔴 三处「看起来做了、实际没生效」

### 3.1 分页永远不触发（`/page/2/` 404）

```ts
// src/pages/index.astro
const POSTS_PER_PAGE = 8;
const totalPages = Math.ceil(sortedPosts.length / POSTS_PER_PAGE);  // 8 / 8 = 1
...
{totalPages > 1 && <Pagination ... />}   // 永远不渲染
```

```ts
// src/pages/page/[page].astro
if (totalPages <= 1) return [];          // 不生成任何 /page/N 路由
```

**实测**：`/page/2`、`/page/2/` 均返回 **404**；运行时首页 HTML 里搜不到 `pagination-nav`。

**修复二选一**：

- ✅ **推荐**：把示例文章补到 **16 篇**（或 17+），这样 `totalPages=2`、`/page/2/` 有 8 篇内容，既能验收分页，也更接近原版「长首页 + 分页」的观感；
- 临时方案：把 `POSTS_PER_PAGE` 调到 5（8 篇 → 2 页），但首页只有 5 张卡片，视觉密度比原版 8 张稀疏。

> 建议同时补一篇 9+ 图的文章，让 `+23` 那种大角标在首页可见（现在 `welcome.md` 10 张 → `+1`，运行时共 3 处 `img-overlay`）。

### 3.2 Giscus 是占位配置，评论区加载必然失败

`src/pages/posts/[slug].astro:143-146`：

```js
script.setAttribute('data-repo', 'OWNER/REPO');
script.setAttribute('data-repo-id', 'REPLACE_WITH_YOUR_REPO_ID');
script.setAttribute('data-category', 'Announcements');
script.setAttribute('data-category-id', 'REPLACE_WITH_YOUR_CATEGORY_ID');
```

**修复步骤**（需要你提供信息，AI 无法代填）：

1. 准备一个**公开的 GitHub 仓库**，在 Settings → General → Features 勾选 **Discussions**；
2. 到 <https://giscus.app/> 输入仓库名，按指引拿到 `repoId` 与 `categoryId`（选 `Announcements` 分类）；
3. 把三个占位值换成真实值；`data-mapping="pathname"` 保持不变；
4. 在仓库安装 giscus app 并授权。

> 若不想依赖 GitHub，可改接 Twikoo（需 Cloudflare Workers / Vercel 后端）或先放一个静态「评论已关闭」占位块，至少不要留一个会报错的空容器。

### 3.3 顶栏多余按钮：上轮的 CSS 特异性 bug 换元素复发

**现象**：v5 顶栏右侧是「搜索输入框 + 蓝色按钮 + **放大镜圆按钮** + 灯泡圆按钮」，原版只有 2 个圆按钮（搜索图标 + 主题切换）。

**根因**：本轮新增的移动端搜索链接

```astro
<a href="/search" class="lg:hidden header-icon-btn" aria-label="搜索">
```

与 `mobile-menu-toggle` 一样，被 scoped `.header-icon-btn[data-astro-cid-3ef6ksr2]{display:flex}`（特异性 0,2,0）压过 `@media(min-width:1024px){.lg\:hidden{display:none}}`（0,1,0）。上轮的兜底规则只写了 `#mobile-menu-toggle`，**没覆盖这个新 `<a>`**。

运行时 HTML 里两个 `lg:hidden` 元素都在：

```
<a href="/search" class="lg:hidden header-icon-btn" ...>
<button id="mobile-menu-toggle" class="lg:hidden header-icon-btn" ...>
```

**修复（一次覆盖两个，避免再加元素时复发）**：

```css
@media (min-width: 1024px) {
  #mobile-menu-toggle,
  .header-icon-btn.lg\:hidden { display: none !important; }
}
```

或者更彻底：**把 `display:flex` 从 scoped `.header-icon-btn` 里拿掉**，改由 Tailwind 的 `flex` 工具类提供，这样所有 `lg:hidden` 都能正常生效，不再需要逐个 ID 打补丁。

### 3.4 顺带：顶栏搜索形态与原版不同 🟡

v5 用了 `#c_sousuo` 这个 ID，但做成**常驻 inline 输入框**（`.search-bar-input{width:120px; border:3px solid #ddd; height:30px}`）。原版是**点击搜索图标后从顶部展开的 120px 高搜索条**：

```css
#c_sousuo { height:120px; }
#c_sousuo .search_box { margin:30px 0; text-align:center; }
#c_sousuo .search_box .ss_a { width:100%; border:3px solid #dddddd;
  line-height:40px; padding:0 15px; }
#c_sousuo .search_box .ss_a input { width:100%; border:none; font-size:12px; }
#c_sousuo .search_box .ss_a button { position:absolute; right:12px; ... }
.dark #c_sousuo { background:#1a1a1a; }
.dark #c_sousuo .search_box .ss_a { border:3px solid #414141; }
```

搜索**功能**已经可用（`/search` 客户端过滤），这一项属形态差异：要么把常驻框改成「点图标 → 顶部展开」，要么保留常驻框但在文档里注明是有意的静态站替代（原版演示站的搜索也是 WordPress 服务端 `?s=`，Astro 静态站做不到完全一致）。
