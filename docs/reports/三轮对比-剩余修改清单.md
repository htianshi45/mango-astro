## 3. 🔴 唯一 P0：九宫格图片整块 CSS 失效（本轮回归）

### 3.1 现象

对照图里：原版第一张卡片是 **3×3 共 9 张正方形小图 + 最后一张 `+23` 角标**，占卡片高度约 230px；本地 v3 是**一张横向大图竖着叠三张**，首屏里只露得出第一张，卡片被撑到 1000px 以上。这是本轮最刺眼的差距。

长图 `/tmp/mango-v3-long.png` 可见三张图片**按原始宽高比垂直堆叠**，完全没有 float 网格、没有方形裁剪、没有 `margin:2%`。

### 3.2 根因（三层叠加，已逐层验证）

| 层 | 事实 | 证据 |
|---|---|---|
| ① 命名不一致 | `PostImages.astro` 输出 `class="post_images post_img_3"`（**下划线**）；`global.css` 定义 `.post-images` / `.post-images.post-img-3`（**中划线**） | 运行时 HTML：`curl -s http://localhost:4321/ \| grep -oE 'class="[^"]*post_images…'` → `class="post_images post_img_3"`、`class="post_images post_img_4"` |
| ② 子元素缺 class | CSS 全部写成 `.post-images .post-img …`，但模板里 `<a>` 只有 `class="lightbox-link relative"`，**根本没有 `.post-img`** | `PostImages.astro:27`；运行时 HTML 只有 `class="lightbox-link relative"` |
| ③ **Tailwind purge** | 这些规则写在 `@layer components` 里，Tailwind 3 会按 content 扫描**丢弃未被引用的类**；因为模板里从没出现过 `post-images`/`post-img-3` 字面量，**整块规则连构建产物都没进** | `dist/_astro/about.DyYm-obg.css` 里 `grep -c '62.67%'` = **0**；含 `post` 的选择器只剩 `.post-loop / .post-loop-tag / .post-tag / .post-info-footer`（这些恰好是模板里用到的名字）；dev 首页内联 CSS 里也搜不到 `.post-images` |

> ⚠️ 所以这不是「样式优先级不够」，而是**规则被删除**。改模板 class 或改 CSS 名，二者必须选一个统一；只改一处仍会被 purge。

### 3.3 最小可靠修复（推荐，可直接粘贴）

**A. `src/components/PostImages.astro`** —— 统一成中划线，并给 `<a>` 加 `.post-img`：

```astro
// getLayoutClass 返回值全部改中划线
if (count === 1) return 'post-img-1';
if (count === 2) return 'post-img-2';
// … 3..8 同理
return 'post-img-9';
```

```astro
<div class:list={['post-images', getLayoutClass(displayImages.length)]}>
  {displayImages.map((image, index) => (
    <a href={image} class="post-img lightbox-link" data-gallery={slug} data-index={index}>
      <img src={image} alt={`图片 ${index + 1}`} loading="lazy" />
      {index === displayImages.length - 1 && remainingCount > 0 && (
        <div class="img-overlay">+{remainingCount}</div>
      )}
    </a>
  ))}
</div>
```

**B. `src/styles/global.css`** —— 把整块 `.post-images*` 规则**移出 `@layer components`**（Tailwind 不 purge 普通 CSS），并修掉 `img` 的高度冲突：

```css
/* 放在 @layer 之外，避免被 purge */
.post-images { width: 66%; font-size: 0; display: table; margin: 0 -1%; }
.post-images > a.post-img {
  display: inline-block; float: left; position: relative;
  border-radius: 8px; overflow: hidden; margin: 2%;
}
.post-images > a.post-img > img {
  display: block; width: 100%;
  height: auto;                 /* 删掉 height:340px */
  aspect-ratio: 1 / 1;          /* 原版是 340x340-c 方图 */
  object-fit: cover;
}
.post-images.post-img-2 > a { width: 46%; }
.post-images.post-img-3 > a:first-child { width: 62.67%; }
.post-images.post-img-3 > a:not(:first-child) { width: 29.33%; }
.post-images.post-img-4 > a { width: 46%; }
.post-images.post-img-5 > a:nth-child(-n+2) { width: 46%; }
.post-images.post-img-5 > a:nth-child(n+3) { width: 29.33%; }
.post-images.post-img-6 > a:first-child { width: 62.67%; }
.post-images.post-img-6 > a:not(:first-child) { width: 29.33%; margin: 2.2% 2%; }
.post-images.post-img-7 > a:nth-child(-n+3) { width: 29.33%; }
.post-images.post-img-7 > a:nth-child(n+4) { width: 21%; }
.post-images.post-img-8 > a:nth-child(-n+2) { width: 46%; }
.post-images.post-img-8 > a:nth-child(n+3) { width: 29.33%; }
.post-images.post-img-9 > a { width: 29.33%; }
```

> 现有 `height:340px` 与 `aspect-ratio:1/1` 同时写会互相打架；且 29.33% 宽度的小图只有约 100px 宽，固定 340px 高会拉成竖条。**必须改成 `height:auto` + `aspect-ratio`**。

**C. 内容补数据**：两篇 md 的 `images` 仍是 3 / 4 张且是 Unsplash 外链。建议补到 **9 张以上**（本地化到 `public/images/`），才能触发 `post-img-9` 与 `+N` 角标，把 8 套布局全部验收一遍。

**D. 验收命令**：

```bash

"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-sandbox --no-proxy-server --hide-scrollbars \
  --user-data-dir=/tmp/chrome-v4 --window-size=1440,1000 \
  --virtual-time-budget=2200 --screenshot=/tmp/mango-v4.png http://localhost:4321/
```

（`--virtual-time-budget` 保持 **<5000**，否则会截到轮播第 2 帧。）
