Mango Astro 站点管理与设置教程

适用站点：https://mango-astro.pages.dev（mango-astro 工程） 最后更新：2026-11-07

0. 先认清这个站由哪几块组成

组成部分 是什么 在哪
Astro 静态站点生成器，把 Markdown 和组件编译成 HTML 本机 /Users/ming/mango-astro
GitHub 仓库 存放源码，也是 CMS 写入文章的地方 github.com/htianshi45/mango-astro（Private）
Cloudflare Pages 托管编译后的静态文件 mango-astro.pages.dev
Sveltia CMS 浏览器里的写文章后台（中文界面） /admin/
OAuth 网关 让 CMS 能安全登录 GitHub 的中间层 auth.840428.xyz（Cloudflare Worker）

数据流是这样的：

你在 /admin/ 写文章
   → Sveltia 调 GitHub API，把 Markdown 提交进仓库
   → 仓库出现新 commit
   → （若接了 Git 构建）Pages 自动重新编译 → 线上更新

关键认知：这是静态站点，没有「后台设置面板」。除了文章内容，所有站点设置（站名、导航、Banner、备案号、主题色）都写在源码文件里。改完必须重新构建 + 部署才生效。

1. 三种操作，先分清

你想做的事 用什么 要改代码吗 要重新部署吗
写文章、改文章、传图 /admin/ 后台 不用 看是否接了 Git 构建
改站名、导航、Banner、备案号、颜色 改源码文件 要 要
让改动上线 npm run build + 部署 — —

2. 写文章（最常用）

2.1 用后台（推荐）

  1. 打开 https://mango-astro.pages.dev/admin/
  2. 点 「使用 GitHub 登录」 → 授权（第一次需要，之后长期有效）
  3. 左侧 文章 → 右上角 新建
  4. 按下面第 2.3 节填字段
  5. 右上角 保存（会直接提交到 GitHub）

如果不想走 OAuth 弹窗，登录页还有 「使用访问令牌登录」，粘贴一个 ghp_ 开头的令牌即可。

注意：后台保存 = 直接 commit 到 GitHub，不会写你本地硬盘。本地要 git pull 才能看到。

2.2 手动写 Markdown

在 src/content/posts/ 新建 你的文件名.md，开头必须有 frontmatter：

---
title: 文章标题
description: 一句话摘要（会显示在卡片上）
pubDate: 2026-11-07
heroImage: /images/test-1.jpg
images:
  - /images/test-1.jpg
  - /images/test-2.jpg
  - /images/test-3.jpg
author: 大明白
avatar: /images/avatar-1.svg
tags:
  - 摄影
  - 风景
category: 风景
sticky: 0
views: 0
comments: 0
likes: 0
draft: false
---

正文从这里开始，支持标准 Markdown。

2.3 字段说明（对应 src/content/config.ts）

字段 类型 必填 说明
title 字符串 ✅ 文章标题
description 字符串 — 卡片摘要，不填则卡片不显示摘要行
pubDate 日期 ✅ 发布日期，决定排序
updatedDate 日期 — 更新日期
heroImage 路径 — 封面图，用于热门文章小工具
images 字符串数组 — 九宫格图片，最多展示 9 张
author 字符串 — 默认 Mango，建议改成你的名字
avatar 路径 — 作者头像
tags 字符串数组 — 标签，会生成 /tags/标签名 页面
category 字符串 — 分类，会生成 /categories/分类名 页面
sticky 数字 — 置顶权重，越大越靠前，0 表示不置顶
views / comments / likes 数字 — 静态展示数字（不是真实统计）
draft 布尔 — true 则不发布

2.4 图片怎么放

  • 图片统一放 public/images/，引用时写 /images/文件名.jpg
  • 文件名建议英文/数字，中文也能用但 URL 会被编码
  • 九宫格规则（src/components/PostImages.astro）：
  • 1 张 → 单张大图（16:9）
  • 2 张 → 两列
  • 3–9 张 → 三列方形
  • 超过 9 张 → 只显示前 9 张，第 9 张盖一层 +N 角标，点开可翻看全部
  • 建议单张压缩到 300 KB 以内，宽度 1200–1600 px 足够
  • 点击图片会全屏放大（从缩略图原位放大，支持左右滑、双击缩放）

3. 改站点信息（对照表）

这一节是「改哪里」的字典。站点设置现在集中在 src/config/site.ts，站名、Logo、描述、备案号、导航、页脚、功能开关、订阅开关都在里面改；改完重新构建 + 部署。

想改什么 文件 具体位置
站名 + Logo src/config/site.ts siteConfig.name / siteConfig.logo
顶部导航菜单 src/config/site.ts siteConfig.navItems 数组
页脚链接 src/config/site.ts siteConfig.footerLinks 数组
页脚版权 src/components/Footer.astro 自动取 siteConfig.name，无需单独改
ICP 备案号 src/config/site.ts siteConfig.icp，留空则不显示（占位文案已移除）
功能开关 src/config/site.ts features（TOC / 进度 / 字数 / 阅读时间 / 上下篇 / 分享）与 feed（RSS / Atom / sitemap）
页面开关 src/config/site.ts pageToggles，关掉会同时隐藏导航并让该页返回 404
首页轮播 src/config/banner.ts banners 数组
主题主色 tailwind.config.mjs 第 8–13 行 colors.mango
深色模式色值 tailwind.config.mjs 第 14–19 行 colors.dark
每页文章数 src/config/site.ts siteConfig.postsPerPage（首页与分页共用）
站点域名 src/config/site.ts + astro.config.mjs siteConfig.url 与 site 必须保持一致
浏览器标题后缀 各页面文件 <BaseLayout title="首页 - Mango"> 里的 - Mango
默认 meta 描述 / SEO src/config/site.ts + BaseLayout.astro siteConfig.description；OG / JSON-LD 由 BaseLayout 自动生成
关于页内容 src/pages/about.astro 整页正文，目前还是模板文案
评论功能 src/config/comment.ts giscusConfig，enabled: false 表示关闭
后台字段 public/admin/config.yml 增删字段、改默认值

3.1 改导航菜单的具体写法

src/config/site.ts 的 siteConfig.navItems：

navItems: [
  { name: '风景', href: '/categories/风景' },
  { name: '旅拍', href: '/categories/旅拍', icon: 'bi-palette' },
  {
    name: '科技', href: '/categories/科技',
    children: [{ name: '数码', href: '/categories/数码' }],
  },
  { name: '主题下载', href: '/download', page: 'download' },
],
  • name 显示文字，href 链接
  • icon 可选，用 Bootstrap Icons 类名（如 bi-palette）
  • children 存在即自动生成二级下拉菜单
  • page 关联页面开关；对应开关设为 false 时，该导航项自动消失
  • 加一项就复制一行，删一项就删一行

3.2 改轮播的具体写法

src/config/banner.ts：

export const banners: BannerItem[] = [
  {
    title: '干净通透的沉浸式工作台[文章分页效果]',
    image: '/images/banner-1.jpg',   // 图片放 public/images/
    url: '/posts/welcome',           // 点击跳转
    sticky: true,
  },
  // 想加就继续往下写
];
  • 图片建议 900×350 或 16:9 横图（aspect-ratio: 900/350，宽屏变 21/9）
  • 用方图会被裁切，只剩中间一条
  • 不要填网页链接当图片，必须是图片文件

4. 主题色怎么改（三处要一起改）

主色不是只改一个地方，目前有三处硬编码：

位置 内容
tailwind.config.mjs 第 8–13 行 mango: { light, DEFAULT, dark, hover }
src/components/Header.astro 搜索按钮 hover 色 #4270f5
src/components/Footer.astro Powered by 链接 #4270f5

改色建议：选定一个主色（如 #e8590c 橙），然后：

mango: {
  light: '#ff8a4c',    // 浅一档，用于深色模式下的链接
  DEFAULT: '#e8590c',  // 主色
  dark: '#b8440a',     // 深一档
  hover: '#a33d08',    // hover 态
},

再把 Header.astro / Footer.astro 里的 #4270f5 一起换成 #e8590c，否则会有颜色不一致。

5. 发布上线

5.1 手动部署（当前方式）

cd /Users/ming/mango-astro
npm run build
wrangler pages deploy dist --project-name mango-astro --branch main --commit-dirty=true

如果提示 command not found: wrangler，先执行：

export PATH="$HOME/.local/bin:$PATH"

成功标志：最后出现 ✨ Deployment complete! 和一个 https://xxxxx.mango-astro.pages.dev 链接。

5.3 订阅与 SEO（已内置，无需额外操作）

  • https://mango-astro.pages.dev/rss.xml — RSS 2.0，16 篇文章
  • https://mango-astro.pages.dev/atom.xml — Atom 1.0
  • https://mango-astro.pages.dev/sitemap.xml — 50 条 URL（含文章 / 标签 / 分类 / 分页，不含后台）
  • 每页自动输出 canonical、OpenGraph、Twitter card、JSON-LD；文章页用 BlogPosting 结构
  • 想关掉：把 src/config/site.ts 里 feed.rss / feed.atom / feed.sitemap 设为 false

5.2 自动部署（推荐开启）

现在后台写完文章，线上不会自动更新。开启 Git 构建后就能闭环：

  1. https://dash.cloudflare.com/ → Workers & Pages → mango-astro
  2. 顶部 Settings → 左侧 Builds & deployments
  3. Git repository 那一行点 Connect（或 Connect to Git）
  4. 授权 GitHub → 选 htianshi45/mango-astro → Begin setup
  5. 构建配置： - Production branch → main - Framework preset → Astro - Build command → npm run build - Build output directory → dist
  6. Save and Deploy

之后：后台保存文章 → GitHub commit → Pages 自动重编译 → 线上更新。

6. 后台维护

6.1 两种登录方式

方式 操作 适合
GitHub OAuth 点「使用 GitHub 登录」→ 授权 日常用，一次授权长期有效
访问令牌 点「使用访问令牌登录」→ 粘 ghp_ 令牌 OAuth 出问题时的备用通道

6.2 网关自检

后台登录不了，先查网关是否健康：

curl https://auth.840428.xyz/health

正常应返回：

{ "ok": true, "client_id_configured": true, "client_secret_configured": true,
  "allowed_origins": ["...", "https://mango-astro.pages.dev", "https://mango.840428.xyz"],
  "callback_url": "https://auth.840428.xyz/callback" }

两个 configured 必须都是 true，否则去 oauth-gateway/ 重新 wrangler secret put。

6.3 换 OAuth 密钥

# 1. GitHub → Settings → Developer settings → OAuth Apps → Mango CMS
#    点 Generate a new client secret，复制新的，旧的 Delete
# 2. 填进网关
cd /Users/ming/mango-astro/oauth-gateway
wrangler secret put GITHUB_CLIENT_SECRET

换完不影响已登录状态。

6.4 网关重新部署

改过 oauth-gateway/worker.js 或 wrangler.toml 后：

cd /Users/ming/mango-astro/oauth-gateway
wrangler deploy

7. 备份与回滚

这个工程是 git 仓库，每次改动前先提交，出问题能一键回退。

cd /Users/ming/mango-astro
git add -A
git commit -m "改了什么"
git push

回滚：

# 看历史
git log --oneline

# 撤销某一次提交（生成一个反向提交，安全）
git revert <commit-hash>
git push

# 只恢复某个文件到某个版本
git checkout <commit-hash> -- src/components/Header.astro

CMS 与本地的关系：后台改文章是提交到 GitHub，本地要 git pull 才同步。如果本地也改了同一篇，pull 会冲突，先提交本地改动再 pull。

8. 故障排查

现象 原因 处理
后台白屏 脚本加载失败或初始化报错 打开浏览器控制台看红色报错；确认 /admin/sveltia-cms.mjs 返回 200
点登录没反应 弹窗被拦截 地址栏右侧允许弹窗
弹窗停在「正在跳转」 网关握手失败 查 /health；确认 base_url 是 https://auth.840428.xyz
redirect_uri mismatch OAuth App 回调地址不对 必须是 https://auth.840428.xyz/callback
登录后看不到文章 仓库名/分支错 config.yml 的 repo 应为 htianshi45/mango-astro，branch 为 main
保存文章报 403 令牌权限不足 用 classic 令牌，勾整块 repo
图片不显示 路径写错 必须是 /images/xxx.jpg（以 / 开头），文件在 public/images/
构建失败 frontmatter 字段类型错 对照第 2.3 节；tags/images 必须是数组
改了没生效 没重新部署 npm run build + wrangler pages deploy，或开 Git 自动构建
command not found: wrangler PATH 里没有 export PATH="$HOME/.local/bin:$PATH"
Failed to connect 127.0.0.1:7890 全局 git 代理指向死端口 git config --global --unset http.proxy
终端连不上 auth.840428.xyz 本机 DNS 缓存没更新 sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder，或直接用浏览器访问
