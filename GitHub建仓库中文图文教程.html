GitHub 建仓库 · 中文图文教程

给不熟悉英文界面的你：每个英文按钮都标了中文含义，以及「这里到底该填什么」。

本教程只解决一件事：在 GitHub 上建好一个空仓库，让本地代码能推上去。建完之后配 remote、推送、填 CMS 配置这些，我可以直接帮你做。

第 0 步 · 你有没有 GitHub 账号

已经有账号：直接跳到第 1 步。

没有账号：打开 https://github.com/signup，逐字段对照：

英文原文中文含义你要填什么
Email邮箱常用邮箱，后面要收验证码
Password密码至少 15 位，或 8 位以上含数字和小写字母
Username用户名英文/数字/连字符，这个就是你的 GitHub 账号名，记下来
Enter code输入验证码邮箱里收到的 8 位数字
用户名很关键。后面仓库地址是 https://github.com/你的用户名/仓库名，我配 remote 时需要它。

第 1 步 · 打开「新建仓库」页面

登录后，任选一种：

  • 点页面右上角的 + 号 → 菜单里选 New repository（中文：新建仓库）
  • 或者直接在地址栏输入：https://github.com/new

第 2 步 · 填表单（只有 4 处要动）

英文字段中文含义填什么 / 怎么选
Repository name *仓库名填 mango-astro（必填，别用中文和空格）
Description描述留空就行，可选
Public / Private公开 / 私有选 Private（私有），代码不公开
Create repository创建仓库绿色按钮，最后点它

最容易错的地方：中间那三个复选框

表单中间有一行 Initialize this repository with:（中文：用以下内容初始化仓库），下面有三个复选框：

英文原文中文含义要不要勾
Add a README file添加 README 文件不要勾
Add .gitignore添加 .gitignore不要勾
Choose a license选择开源许可证不要勾
为什么三个都不能勾：你本地已经有两个 commit 了。如果 GitHub 那边也生成一次初始提交，就会变成「两套互不相关的历史」，推送时会被拒绝（报 rejected / fetch first），还得额外处理。保持空仓库最省事。

第 3 步 · 创建成功，复制仓库地址

点完 Create repository 后会跳到一个空仓库页面，地址类似：

https://github.com/你的用户名/mango-astro

把这个地址（或用户名）发给我，我就能接着配 remote、推送、填 CMS 配置。

第 4 步 · 我接手做什么

  1. 把 origin 指到你的仓库，检查连通性
  2. 把本地 2 个 commit 推上去（认证时你只需输入一次用户名 + PAT）
  3. 把 public/admin/config.yml 里的 repo、site_domain 填好并提交

附录 A · 更省事：用命令行一步建好

如果你愿意在终端粘贴命令，这条路最快（我已经在帮你装 gh）：

brew install gh
gh auth login
# 依次用方向键选：
#   ? What account do you want to log into?        → GitHub.com
#   ? What is your preferred protocol for Git?      → HTTPS
#   ? Authenticate Git with your GitHub credentials? → Yes
#   ? How would you like to authenticate?           → Login with a web browser
# 然后复制终端里的一次性代码，粘贴到打开的网页里授权

授权成功后，一条命令就能建仓库 + 推送 + 设好 remote：

cd /Users/ming/mango-astro
gh repo create mango-astro --private --source=. --remote=origin --push
或者：你只完成 gh auth login，然后告诉我一声，这条 gh repo create 由我来执行。

附录 B · 后面还要建 OAuth App（同样全英文，先给对照）

仓库建好后，后台登录还需要一个 OAuth App。打开 https://github.com/settings/developers → 点 OAuth Apps → New OAuth App，逐字段填：

英文字段中文含义填什么
Application name应用名称Mango CMS
Homepage URL主页地址https://mango.840428.xyz
Authorization callback URL授权回调地址https://auth.840428.xyz/callback（一字不差）
Register application注册应用绿色按钮，点它

创建后页面上：

  • Client ID → 直接复制
  • Generate a new client secret → 点它生成密钥，只显示一次，立刻复制

附录 C · PAT 怎么生成（推送认证要用，也是英文）

GitHub 早就不支持用账号密码推送了，必须用 Personal Access Token（个人访问令牌）：

  1. 打开 https://github.com/settings/tokens
  2. 点 Generate new token → Generate new token (classic)
  3. Note（备注）填 mango-astro；Expiration（有效期）选 90 days
  4. Select scopes（权限范围）勾选 repo（这一整块）
  5. 拉到底点 Generate token，复制以 ghp_ 开头的字符串（只显示一次）

推送时提示 Username 填你的 GitHub 用户名，Password 处粘贴这个 token（不是账号密码）。macOS 钥匙串会记住。

附录 D · 常见报错对照

报错原因与处理
Fastly error: unknown domain: github.com代理软件把 github.com 转发到了 GitHub Pages 的 IP（185.199.x）。关掉「GitHub 加速」规则，或让 github.com 走直连
Failed to connect to 127.0.0.1 port 7890git 全局代理指向了没启动的 7890 端口。本仓库我已设空代理绕过；其他工程可 git config --global --unset http.proxy
remote: Repository not found仓库没建、名字拼错，或 token 没有该仓库权限
Authentication failed在 Password 处填了账号密码。要填 PAT（ghp_ 开头）
src refspec main does not match any本地分支不叫 main。执行 git branch -M main
rejected ... fetch first建仓库时勾了 README/.gitignore。删掉仓库重建（三个都不勾），或 git pull --rebase origin main

一句话总结

打开 https://github.com/new → 仓库名填 mango-astro → 选 Private → 中间三个复选框全部不勾 → 点 Create repository → 把地址发我。
